# Maryam Sherif Portfolio

Static portfolio site (HTML + CSS, no build step).

## Publish with GitHub Pages
1. Create a GitHub repo named `maryam-sherif-portfolio` and upload everything in this folder.
2. Repo **Settings > Pages**: Source = *Deploy from a branch*, Branch = `main`, folder = `/ (root)`.
3. Your site goes live at `https://mariam123sherif.github.io/maryam-sherif-portfolio/`.

## Use your own domain
1. Buy a domain, then in **Settings > Pages > Custom domain** enter it (e.g. `maryamsherif.com`).
2. At your domain registrar add DNS records: four `A` records to `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`, and a `CNAME` for `www` pointing to `mariam123sherif.github.io`.
3. Tick **Enforce HTTPS** once the certificate is ready.
